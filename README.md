# Посмотри в окно

Учебный проект Яндекс Практикума: интерфейс для просмотра видеозарисовок из разных городов. Ролики можно искать по городу и времени суток, а затем выбирать из списка карточек.

Вёрстка выполнена на HTML и CSS. Поиск и загрузка видео работают через JavaScript и API Практикума.

## Локальный запуск

В корне проекта запустите:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/). Для загрузки видео нужен доступ к API Практикума.
